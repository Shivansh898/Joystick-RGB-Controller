# Joystick RGB Controller - Bill of Materials

| Qty | Component | Description / Notes |
|-----|-----------|---------------------|
| 1 | Raspberry Pi | Main controller that executes the program, processes joystick inputs, controls the LED, and communicates with peripheral modules. |
| 1 | Raspberry Pi GPIO Extension Board | 40-pin GPIO breakout board that expands the Raspberry Pi GPIO header onto a breadboard for easy prototyping and wiring. |
| 1 | 40-Pin Ribbon Cable | Connects the Raspberry Pi GPIO header to the GPIO extension board mounted on the breadboard. |
| 1 | Solderless Breadboard | Reusable prototyping platform used to make electrical connections between components without soldering. |
| 1 | Analog Joystick Module | Two-axis joystick module with an integrated pushbutton used for user input and directional control. |
| 1 | ADC Module (Analog-to-Digital Converter) | Converts the analog voltage signals generated by the joystick into digital signals that can be processed by the Raspberry Pi. |
| 1 | 5 mm RGB LED | Visual output device used to display colors and system status indications based on joystick position or program logic. |
| 3 | 220 Ω Resistors | Current-limiting resistors used to protect the RGB LED channels from excessive current. |
| 20 | Male-to-Male Jumper Wires | Electrical connection wires used to connect the GPIO breakout board, ADC module, joystick module, LED, and power rails. |
| 1 | Raspberry Pi Power Supply | Regulated 5 V power source used to power the Raspberry Pi and connected circuitry. |
| 1 | MicroSD Card | Storage device containing the Raspberry Pi operating system, project files, and application code. |
