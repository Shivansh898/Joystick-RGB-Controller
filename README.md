🌈 ChromaStick
ChromaStick is a Raspberry Pi-powered RGB lighting controller that uses a joystick to dynamically control LED colors in real time.

By translating joystick movement into RGB values, users can create and explore a wide range of color combinations through an intuitive and interactive interface. The project combines hardware and software to demonstrate GPIO programming, PWM control, analog input processing, and real-time user interaction.

Features
🎮 Joystick-controlled RGB lighting
🌈 Real-time color mixing
⚡ Responsive LED color changes
🔧 Raspberry Pi GPIO integration
💡 Interactive hardware project
Hardware Used
Raspberry Pi
RGB LED
Joystick Module
Breadboard
Jumper Wires
Resistors
How It Works
The joystick continuously sends positional data to the Raspberry Pi. The software reads the X and Y values and converts them into RGB color values, allowing the LED to change color based on joystick movement.
