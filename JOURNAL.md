Devlog 1 - Joystick RGB Controller
What I Built
Today I worked on my Joystick RGB Controller project using a Raspberry Pi. The system allows a joystick to control the colour of an RGB LED in real time. By moving the joystick, different red, green, and blue values are adjusted to create a wide range of colours.

Challenges
One of the main challenges was reading the joystick input correctly and mapping those values to the RGB LED output. I also spent time testing and debugging the code to make the colour transitions smoother and more responsive.

What I Learned
Through this project I learned more about GPIO programming, analog input handling, PWM control, and how hardware and software can interact to create an interactive system.

What's Next
Next, I would like to add preset colour modes, brightness controls, and more advanced lighting effects. I also want to improve the user experience by making the controls more intuitive and adding additional features.
